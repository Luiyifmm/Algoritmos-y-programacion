# Sistema de Gestión de Estudiantes (SGE) básico

Aplicación de consola en Python 3.10 o superior (usa `match/case`).

## Funcionalidades
1. Agregar estudiante (ID único, nombre, programa y nota de 0.0 a 5.0)
2. Mostrar estudiantes en orden ascendente o descendente, con el promedio general
3. Buscar estudiante por ID
4. Salir

## Ejecución
```bash
python sge.py
```

## Conceptos aplicados
Decisiones simples, anidadas y múltiples (`match/case`), ciclos `while` y `for` (ascendente y descendente),
variables de conteo, sumatoria y bandera, lista de diccionarios con capacidad máxima de 50,
validación de entradas con `try/except` y funciones reutilizables.
